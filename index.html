Step 1 — Raw data from multiple sources

Three ad platforms are feeding campaign names into MI. Each source uses the same internal naming convention, but the raw data has no structured dimensions like company, audience, or objective.

Click Detect pattern to let MI scan the campaign names and figure out the delimiter and number of positions being used.

Step 2 — Pattern detected

MI scans every campaign name across all sources, tests common delimiters, and identifies the most consistent structure.

The pattern is [value]|[value]|[value]. Now tell MI what each position represents.

Step 3 — Name the positions

MI has guessed labels by sampling the values at each position. Review them and edit if needed. These will become brand new dimensions in your dataset.

These labels become the names of the dimensions that MI will populate.

Step 4 — Deconstruct every matching campaign

MI splits each matched campaign name at the delimiter and tags each piece with its labeled position.

Each chip is a value extracted for a dimension. Values from all sources will be combined next.

Step 5 — Harmonized dimensions

Extracted values become real columns. Data from every source is now unified on the same set of dimensions — even though those dimensions did not exist in any source to begin with.

You can now analyze combined data across sources by these new dimensions.

Step 6 — Analyze by dimensions that did not exist before

The same raw campaign strings now power cross-source breakdowns — the core value of the Patterns feature.

That’s the Patterns workflow: detect → label → deconstruct → harmonize → analyze.
